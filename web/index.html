dos-gatos

Firmware for the Ulanzi TC001 pixel clock. The clock decides what to fetch and when; a small macOS agent does the HTTPS requests over USB. No Wi-Fi needed.

Back up your current firmware first. The browser flasher cannot read the flash back. If you may want the stock firmware or AWTRIX later, save it with esptool: 
pip install esptool
esptool.py --chip esp32 --port /dev/cu.usbserial-XXXX read_flash 0 0x400000 tc001-backup.bin

Your browser can't talk to USB devices. Use desktop Chrome or Edge. This page must be opened over HTTPS.

Before you click

  1. Connect the clock with a USB-C data cable. Charge-only cables don't work.
  2. Turn the clock on. It is invisible to the computer while it's off.
  3. Close anything holding the port: TC001 Agent, Arduino IDE, PlatformIO, serial monitors.
  4. In the dialog, pick USB Serial / CH340 (on some revisions CP2102).

Flashing takes about a minute. Settings stored on the clock are kept unless you choose to erase the device.

After flashing

The clock shows --:-- with a red dot: it's waiting for the agent. Install TC001 Agent from the latest release, open it and the clock gets time and data within a few seconds.

Going back

esptool.py --chip esp32 --port /dev/cu.usbserial-XXXX --baud 460800 write_flash 0x0 tc001-backup.bin

AWTRIX has its own web flasher and can be installed over this firmware directly.
